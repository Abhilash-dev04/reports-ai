# Screenshot Guidelines

Add only sanitized screenshots.

Before committing a screenshot, verify that it contains no:

- organization logo or internal product name
- real employee or customer information
- real report identifiers or SQL
- production URLs, tokens, emails, or database names
- browser bookmarks or desktop notifications containing sensitive text

Recommended screenshots:

1. Public demo login page
2. Synthetic dashboard
3. Standard User view without Review Requests navigation
4. Reviewer view with Review Requests navigation
5. Synthetic Review Requests queue
6. Traditional search using `DEMO-RPT-001`
7. Natural-language requested-field result
8. Complete-details tabs with synthetic SQL
9. Reviewer workflow using fictional users
